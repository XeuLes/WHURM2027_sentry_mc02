# CAN3 v3 主副板接口

mainControl 与 subControl 都使用 MC02，分支分别构建固件，不使用 BOARD_ROLE。
主控规划模式、底盘目标和大 Yaw 目标，直接驱动小云台和发射；副板执行底盘、大 Yaw
闭环及原有功率/超级电容控制。两端 `board_link_can.hpp` 必须一致，并同时更新固件。

## 总线与周期

保留 `.ioc`、生成的 FDCAN 配置和 BSP：CAN3 为 1 Mbit/s、11 位标准 ID、经典 CAN、
TX FIFO、关闭自动重发。所有周期帧 DLC 都是 8，应用目标周期均为 1 ms。

| ID | 方向 | 内容 |
| --- | --- | --- |
| 0x11，类型 ACCEL_DATA | DM → 主控 | 三轴加速度，m/s² |
| 0x11，类型 GYRO_DATA | DM → 主控 | 三轴角速度，rad/s |
| 0x310 | 主 → 副 | 底盘系 vx/vy/wz、底盘模式、有效位、序号 |
| 0x311 | 主 → 副 | 大 Yaw 目标、反馈/轨迹、模式、使能、有效位、序号 |
| 0x313 | 主 → 副 | 裁判功率上限、缓冲能量、源数据年龄、有效位、序号 |
| 0x31A | 副 → 主 | 实测底盘系 vx/vy/wz、大 Yaw 机械偏角、状态和序号 |

不再发送 0x312 偏角帧，也不再发送 v2 的 0x318、0x319 独立反馈。
主控用反馈的大 Yaw 机械偏角与本地小 Yaw 机械偏角得到枪口相对底盘总偏角。
直接遥控平移目标按该总偏角转到底盘系；自动 USB 平移目标已在导航的 chassis_link 系，直接下发。
副板直接使用收到的底盘系速度，不重复旋转。

每个标准 8 字节帧按含最坏位填充与帧间隔的 135 bit 预算：
`6 × 1000 × 135 = 810000 bit/s`，即 **81%**。代码保留此预算的静态断言。
这不包括额外报文、错误帧等流量；1 kHz 调度不等于硬件保证每秒送达 1000 帧。
默认关闭自动重发，仲裁失败或传输错误可能丢帧，任务延误后不会突发补发积压周期。
使用接收序号、失败计数与 CAN 分析仪验证送达率和真实总线负载。
`g_can3_load` 是基于接收帧数和发送入队数的预算估计，并非物理总线占用测量。

## 下行格式

多字节字段小端。三条下行帧同周期共享 8 位序号，各自独立更新/超时。
`flags` 高半字节为 v3，即 0x30；低半字节含业务标志。旧 v2 下行帧会被拒绝。
重复/倒序帧不刷新时效；超时后允许新的序号基准，包括重启后碰巧相同的序号。

- 0x310：三个 int16，比例 1000，单位 m/s、m/s、rad/s；后跟 flags 和 sequence。
  flags bit0..1 为底盘模式，bit2 为有效位，bit3 为变形停车联锁。模式变化先清除速度环历史。
  联锁置位时副板对有效目标执行零速度闭环，不执行载荷中的非零速度；解除后执行最新目标。
- 0x311：三个 int16，依次为 target、position_or_acceleration、velocity；后跟 flags 和 sequence。
  flags bit0 使能、bit1 目标有效、bit2 机械偏角模式。

| 大 Yaw 模式 | target | position_or_acceleration | velocity | 副板实际反馈 |
| --- | --- | --- | --- | --- |
| IMU 航向 | 目标航向，0.0001 rad/LSB | 主控 BMI088 实际航向，0.0001 rad/LSB | 实际航向角速度，0.002 rad/s/LSB | 该帧携带的 BMI088 姿态 |
| 机械偏角 | 目标机械偏角，0.0001 rad/LSB | 轨迹目标加速度，0.01 rad/s²/LSB | 轨迹目标角速度，0.002 rad/s/LSB | 副板直接读取电机机械角和角速度 |

主控 BMI088 安装在大 Yaw 转动件上。枪口 DM 的姿态受小 Yaw 等机构影响，不能直接代替大 Yaw 反馈。
导航过洞保持洞口对应的 BMI088 惯性航向，使用 IMU 航向模式；底盘由导航转到与其对齐。
手动过洞保留机械回中模式。两条路径都要求大 Yaw 实测机械回中确认后才折叠小云台。
副板沿用原 SMC。使能但目标无效时只完成电机握手并输出零力矩；故障锁定须主控明确失能后清除。

0x313：uint16 功率上限 W、uint16 缓冲能量 J、uint8 功率年龄、uint8 缓冲年龄、flags、sequence。
年龄以 10 ms 向上取整，255 表示饱和。flags bit0 裁判在线、bit1 功率已收到、bit2 缓冲已收到。
副板把接收后的经过时间计入源年龄，1 kHz 转发不改变裁判源数据的实际更新频率。

## 合并反馈 0x31A

按小端位流排列前 56 位，四个数均为 14 位二进制补码；不要使用编译器相关的 C 位域。
最后一个字节为状态/序号。反馈版本由新 ID 0x31A 标识，无单独版本半字节。

| 位 | 字段 | 分辨率 / 范围 |
| --- | --- | --- |
| 0..13 | 实测 vx | 0.004 m/s，-32.768..32.764 m/s |
| 14..27 | 实测 vy | 0.004 m/s，-32.768..32.764 m/s |
| 28..41 | 实测 wz | 0.004 rad/s，-32.768..32.764 rad/s |
| 42..55 | 大 Yaw 相对底盘机械偏角 | 0.0004 rad，机械角约束在 ±π |
| 56 | 大 Yaw 电机反馈有效 | 与底盘有效位独立 |
| 57 | 大 Yaw 已使能就绪 | 电机有效时才允许置位 |
| 58 | 大 Yaw 低速 | 电机有效且实测机械角速度绝对值 < 0.05 rad/s |
| 59 | 底盘实测速度有效 | 全轮在线、估计有效、值可编码、源快照 < 10 ms |
| 60..63 | 反馈序号 | 每次发送尝试递增，模 16 |

速度与偏角分别四舍五入编码；超范围/NaN 清除对应有效位，不发送饱和的虚假实测值。
反馈序号有效时接受向前 1..7 步，拒绝重复和倒序；较大丢包可能暂时等待新基准，
20 ms 未接受新反馈后允许重新同步。4 位序号不能区分跨整圈的陈旧报文，不应通过会重放历史帧的桥接器传输。
失能时仍发送反馈心跳，以支持主控启动握手。

主控心跳看门狗 20 ms；副板大 Yaw 目标看门狗 20 ms、底盘目标 50 ms。
主控实际底盘速度存入 `system_state.chassis`，保留接收时间，50 ms 过期或有效位清除即失效。
USB RobotMotion 沿用 ID 0x08 和 10 ms 周期，上报实测底盘系速度、原接收时间及原 CRC 格式；
无效/超时时停发，不回显目标代替实测值。

## 枪口 DM 原始采样与姿态

DM 设备 ID 为 0x01，主机 ID 为 0x11。设备端应配置仅主动输出加速度和角速度，各 1000 Hz；
关闭欧拉角及四元数的周期输出。当前固件没有在启动时写设备寄存器或保存设备参数，
需要用 DM 配置工具设置并抓包确认。额外增加一类 1000 Hz 的 8 字节输出会使预算升至 94.5%，
两类额外输出则达到 108%。只在 MCU 丢弃报文不能降低线上的负载。
欧拉角/四元数请求、解析和缓存接口保留，正常控制任务不调用请求接口。

`app_muzzle_ins.cpp` 在现有 INS_Task 内使用独立 QuaternionEKF 状态解算，不改板载 BMI088 的滤波、
温控或标定。EKF 初始化矩阵、噪声参数、加速度二阶低通、欧拉角转换和去重力计算直接沿用 app_ins.cpp，
仅保留 EKF 路径。DM 加速度从 m/s² 换算成与板载路径相同的 g；BMI088 专用陀螺死区不用于 DM。
只有新陀螺样本才推进滤波，dt 使用接收时间差。
两类样本都必须小于 10 ms；重复/过期数据不刷新姿态时间。大于等于 10 ms 的断流不进行跨空窗积分，
恢复时保留原 yaw 起点，重置加速度低通并等待下一连续采样；加速度融合遵循现有 EKF 算法。
六轴解算的 yaw 从零积分，会受零偏漂移影响；长时间断流期间的运动无法从恢复后的原始样本重建。
上位机绝对角目标须与主控上报的枪口姿态使用同一参考，安装轴向与陀螺零偏仍需实测确认。

板载 BMI088 发布 `system_state.imu`，DM 解算发布 `system_state.muzzle_imu`。
保留原状态字段约定：pitch_rate_dps 存 body X，roll_rate_dps 存 body Y，yaw_rate_dps 存 body Z；
小云台应用已有从机体角速度到欧拉角速度的转换。
